# CyberShield Major Project

## Features
1. Message Scanner
2. Bank / UPI Scanner
3. Job / Internship / Scholarship Scanner
4. URL Scanner
5. Mobile Number Checker (format/region only; no tracking)
6. Email Checker
7. Sender Location Intelligence (only explicitly shared location)
8. Incident Report generation
9. User-controlled Report to Police workflow
10. Cyber Risk Dashboard

## Run
Python 3.10+ recommended.

    pip install -r requirements.txt
    python app.py

Open:
http://127.0.0.1:5000

## Notes
This is a self-contained academic/demo security application. Pattern analysis is heuristic and not a substitute for official verification or threat-intelligence services.
No automatic police complaint is sent.
No secret/current location is derived from a phone number.
